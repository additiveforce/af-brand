# AF Brand

Additive Force brand assets and values: logos, colour, typography and Office theme values. Brand 2.0.

Files are fetched at runtime, so an update here is live for every consumer.

```
https://raw.githubusercontent.com/additiveforce/af-brand/main/[filename]
https://raw.githubusercontent.com/additiveforce/af-brand/main/logos/[filename]
```

## Files

| File | Holds |
|---|---|
| `af-color-system.json` | Every colour with hex, the interior roles (text, muted text, tint, link, status pairs) and the ink pairing for each full-colour ground |
| `af-typography.json` | Geist and the type scale: size, line height, weight, tracking and case per style |
| `af-office.json` | Theme values for PowerPoint, Word and Excel |
| `af-color-system.md` | How to use the colours |
| `af-typography.md` | How to use the type |
| `af-logo.md` | Logo files and placement |
| `af-icons.md` | Which icon set to use |
| `logos/` | Logo SVGs |
| `archive/brand-1.0/` | Brand 1.0 as it stood, kept for reference. Never use it for new work |

The JSON files are generated from AF's private design-system master. Don't edit them by hand.
