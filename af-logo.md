# AF logo

Fetch at generation time and inline exactly as stored:

```bash
curl -s "https://raw.githubusercontent.com/additiveforce/af-brand/main/logos/AF-Logo-Horizontal-Charcoal.svg"
```

## Files

| File | Use |
|---|---|
| `AF-Logo-Horizontal-Charcoal.svg` | Default, on white and light grounds |
| `AF-Logo-Horizontal-White.svg` | On charcoal and on full-colour grounds whose text is white |
| `AF-Logo-Stacked-Charcoal.svg`, `-White.svg` | Where horizontal space is tight |
| `AF-Logo-Icon-Charcoal.svg`, `-White.svg` | The mark alone |
| `af-logo-small-space.svg` | Small sizes, with the mark adjusted to the wordmark |

## Rules

- On a full-colour ground, the logo takes the ground's text colour: white on blue, red, teal, purple and bronze,
  charcoal on jade.
- Never stretch, rotate or redraw the logo. Recolour only by choosing a file, or by setting one fill for the whole
  mark when inlining.
- Clear space on every side equals the height of the AF letterforms.
